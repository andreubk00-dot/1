# OSTATOK 1.23.0-dev4 — Personal Contract Chains

Механическое продолжение 1.23-dev3 по этапу 3 плана разработки: личные поручения постоянных NPC, связанные этапы, исчезающие предложения и последствия отказа/провала.

## Что добавлено

### Четыре личные доски поручений

- **Перрон — Лёнька:** «ЭФИР: РЕЗЕРВНОЕ ПИТАНИЕ» → «ЭФИР: МЁРТВАЯ ЧАСТОТА».
- **Рубеж — Капитан Орлов:** «ОРЛОВ: ПРОПАВШИЙ ПОСТ» → «ОРЛОВ: ПЕРЕДОВОЙ ЗАПАС».
- **Артель «Механики» — Клык:** «КЛЫК: ТЯЖЁЛАЯ ТЕЛЕЖКА» → «КЛЫК: ПРОБНЫЙ ВЫВОЗ».
- **Лазарет — Аркадий:** «АРКАДИЙ: СТАРЫЙ АРХИВ» → «АРКАДИЙ: ПОЛЕВАЯ СЕРИЯ».

Каждая цепочка состоит из двух авторских этапов. Второй этап не появляется до завершения первого.

### Время и последствия

- Личное предложение существует ограниченное число дней и затем исчезает.
- Истёкшее непринятое предложение получает cooldown и не возникает заново в тот же день.
- После принятия у поручения появляется реальный `deadline_day`.
- Просрочка может снижать репутацию, личное отношение NPC и ресурсы поселения.
- Отказ от уже принятого личного поручения также имеет явный штраф.
- Обычные фракционные контракты сохраняют старое поведение; штрафы dev4 не протекают на общий контрактный цикл.
- Если владелец поручения пропал или погиб, активное личное поручение снимается без наказания игрока.

### Последствия для мира

Финальные этапы личных цепочек создают постоянные маршруты/системные эффекты:

- сеть предупреждения Перрона;
- передовой патрульный запас Рубежа;
- грузовая тележка Механиков;
- полевой медицинский протокол Лазарета.

Завершение, провал и отказ отражаются в истории NPC; значимые исходы попадают в мировую хронику.

### Совместимость

- Save schema: **122, без изменения**.
- Новые поля (`personal_offers`, `personal_last_refresh_day`, `deadline_day`, chain/owner metadata) вложены в существующее состояние контрактов/faction state.
- Старые сохранения санитизируются с безопасными значениями по умолчанию.
- Неутверждённая глобальная цель «путь наружу» не реализовывалась.

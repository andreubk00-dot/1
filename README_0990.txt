ОСТАТОК 0.99.0 — VISUAL SHELTER DAMAGE
======================================

ЭТАП
- Визуальные стадии повреждений защитных точек убежища непосредственно в игровом мире.
- Индикация точки, по которой заражённые наносят удары прямо сейчас.

ЧТО ДОБАВЛЕНО
- Двери, окна и построенные баррикады используют четыре визуальные стадии, вычисляемые из их реального HP:
  0 — целое, 1 — повреждено, 2 — критическое повреждение, 3 — пролом.
- Повреждения рисуются процедурно поверх существующего игрового объекта: трещины, сколы и затемнение. Новые PNG-подмены объектов для стадий повреждения не используются.
- Свежий удар заражённого включает короткий янтарный маркер вокруг конкретной атакуемой точки.
- Маркер работает для двери, breach-окна и баррикады и автоматически гаснет после прекращения ударов.
- Визуальное состояние синхронизируется с persistent condition из 0.97/0.98; ремонт сразу восстанавливает соответствующий внешний вид.
- Укреплённое окно сохраняет свою отдельную визуальную характеристику и правильный максимум прочности.
- Для визуальной проверки добавлен QA-режим --qa-shelter-damage.

СОВМЕСТИМОСТЬ
- Формат сохранений не менялся: save_version остаётся 97.
- Новые визуальные стадии не сохраняются отдельно, а каждый раз выводятся из уже существующего HP, поэтому старые сохранения совместимы.
- Механика AI, breach, pressure, ремонт, экспедиции, отдых и снабжение не переписывались.

ТЕСТЫ
- test_shelter_visual_damage.gd: стадии HP, наличие procedural overlay, активный маркер удара и восстановление после ремонта.
- Существующие shelter integrity / breach / defense status тесты остаются обязательными регрессионными тестами.

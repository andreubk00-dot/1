OSTATOK 0.75.0 — ORIGINAL SURVIVOR RIG

Персонаж нарисован с нуля по референсу и полностью заменяет чужой пак.

ПЕРСОНАЖ
- новая модель: каска, борода и усы, оливковая куртка с карманами и молнией, ремень,
  тёмные джинсы, ботинки, рюкзак со скаткой и лямками;
- собирается из 3D-скелета (корпус, таз, бёдра/голени через IK, плечи/предплечья через IK,
  голова) и проецируется в 3/4 top-down пиксель-арт — все 8 направлений согласованы;
- двойная плотность пикселей: кадр 128x128, в игре масштаб 0.5 (SURVIVOR_CELL / SURVIVOR_SPRITE_SCALE).
  Мировой размер персонажа и положение ступней прежние, деталей вдвое больше.

ОРУЖИЕ В РУКАХ
- оружие привязано к костям кистей: правая рука на пистолетной рукоятке, левая на цевье;
  у ПМ хват двумя руками, у ножа — одной, у топора — двумя, у трубы — одной;
- 7 вариантов: без оружия, ПМ, дробовик, АКМ, нож, труба, топор;
- холодное оружие теперь тоже запечено (раньше летающий оверлей) — _modern_survivor_firearm_variant_prefix
  возвращает knife_/pipe_/axe_, pv_weapon_root скрыт для всех видов оружия.

АНИМАЦИИ (все 21 клип контракта, 8 направлений x 8 кадров)
- Idle / Idle2 / Idle3: дыхание, лёгкий поворот корпуса;
- Walk / Run: шаговый цикл с подъёмом стопы, покачивание, наклон вперёд при беге, мах руками без оружия;
- StrafeLeft/Right, RunBackwards (+ Attack-варианты): шаг вбок/назад, оружие остаётся нацеленным;
- Attack1: отдача + вспышка у дула, у дробовика передёргивание цевья на кадрах 3–6;
- Attack3: замах сверху (труба, топор, удар рукой), Attack4: колющий удар (нож, джеб);
- Taunt: перезарядка (левая рука к магазину / цевью);
- TakeDamage: отшатывание; Die: падение (для С/Ю — набок, чтобы читалось на экране);
- CrouchIdle / CrouchRun: присед (в коде пока не вызываются, листы готовы).

КОД
- region_rect и масштаб survivor-спрайта переведены на SURVIVOR_CELL = 128 / 0.5;
- melee-ветка _update_weapon_visual прячет оверлей, когда виден modern survivor;
- selftest: размер листа 1024, наличие 13 ключевых клипов для каждого из 7 вариантов,
  скрытый оверлей для melee.

ЛИЦЕНЗИЯ
- арт персонажа полностью оригинальный; листы стороннего пака и art_source/ удалены.

ИСТОЧНИКИ
- tools/char3d.py (рендерер), tools/survivor3d.py (скелет, одежда, оружие, клипы),
  tools/build_art.py — пересобирает весь арт: python3 tools/build_art.py .
- поменять одежду/цвета/позы — константы и make_pose() в survivor3d.py.

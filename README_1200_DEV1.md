# OSTATOK 1.20.0-dev1 — High-Risk Locations II / Skeleton

Это только **операция 2** из плана 1.20. Стабильная 1.19 не изменяется.

## Что сделано

- версия проекта переведена на `1.20.0-dev1`;
- зарезервированы определения двух high-risk POI второго поколения:
  - `regional_clinical_complex_4` — областной клинический комплекс №4, открытый медицинский кампус, операция 3;
  - `underground_object_vector` — подземный объект «Вектор», закрытый подземный узел, операция 4;
- оба объекта имеют risk 5, `dungeon_tier = 2` и пустой `hard_requirements`;
- определения намеренно находятся в `HIGH_RISK_DEV_SKELETONS`, а не в активном `POIS`.

## Чего в dev1 намеренно НЕТ

Нет compound-геометрии, входов/выходов, контейнеров, loot profile, target farming, заражённых, encounter flow и сложных world events. Это запрещено границей операции 2.

## Постоянные правила

Roadmap сохраняет правила: новые предметы автоматически идут в `ТЕСТ: ВСЕ ПРЕДМЕТЫ`; каждый крупный POI проходит layout QA; сильные вещи дают новую возможность с ценой; после 1.33 Feature Lock крупных механик нет. Discovery-first также остаётся действующим системным правилом.

## Следующая операция

Операция 3 должна полностью реализовать **только областной клинический комплекс №4**: геометрию, вход/выход, препятствия, encounter flow, контейнеры, persistence и отдельные тесты. `Вектор` остаётся определением до операции 4.

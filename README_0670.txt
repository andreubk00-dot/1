OSTATOK 0.67.0 — ORIGINAL CHARACTER INTEGRATION

Correction pass after 0.64-0.66.

Character rules from this build onward:
- the SmallScaleInt FREE Character 16-bit Thug Outlined PNGs are preserved exactly as supplied by the author
- no baked repainting, no recolor, no pasted armor, helmet or backpack layers
- no separate OSTATOK gun sprite is drawn over the imported firearm survivor
- improvements are engine-side only: correct 8-way row mapping, animation clip selection, timing, pivot/scale and state transitions

The original character PNGs in this build were restored directly from the uploaded source archive.

Known limitation:
- the free character contains one baked firearm silhouette, so Makarov/shotgun/AKM cannot honestly look like three different weapons without matching authored character variants. This build prioritizes preserving the original model instead of faking those variants with overlays.

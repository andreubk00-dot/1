# OSTATOK 1.23.0-dev9 — Failed Run Recovery / Vertical Slice Polish

Дата: 2026-10-05

## Задача ветки

Dev9 продолжает полировку 2–4-часового вертикального среза dev7/dev8 без внедрения новой глобальной цели. Фокус — первая неудачная High Risk вылазка: игрок должен понимать последствия incapacitation, иметь честный путь назад в цикл и не получать ни soft-lock, ни бесконечный источник бесплатных расходников.

Базовый цикл остаётся прежним:

**старт → Лазарет → дефицит → Миронова → первый supply incident → аварийный заказ → Клинический комплекс №4 → медицинский груз → Лазарет → восстановление поселения.**

## Что изменено

### Эвакуация после неудачи в Клиническом комплексе

Если активен fresh-game vertical slice, игрок уже встретил Миронову и первый рейс Лазарета разрешён, incapacitation внутри Клинического комплекса №4 теперь имеет отдельный системный исход:

- игрок эвакуируется обратно в Лазарет;
- проходит **6 игровых часов**;
- инвентарь и найденный груз сохраняются — dev9 не вводит новую глобальную механику потери рюкзака;
- состояние восстанавливается только частично (`health 78`, `fatigue 42`, body condition 82), а не до идеальных 100%;
- первая такая эвакуация один раз выдаёт аварийный минимум: **9×18 x8 + бинт x1 + вода x1**;
- повторные эвакуации больше не пополняют этот резерв;
- общий respawn вне клинического среза не менялся.

Это ограничено только первым системным циклом и не превращает Лазарет в универсальную fast-travel/respawn систему.

### HUD / карта после failed run

После первой/повторной эвакуации в Лазарете HUD показывает **«ПЕРЕПРОВЕРИТЬ СНАРЯЖЕНИЕ»** и прямо сообщает о цене эвакуации. Полевая карта показывает системную метку **«ПОЛЕВОЙ МАРШРУТ • ПОВТОР КЛИНИКИ»**.

Когда игрок покидает Лазарет, временный regroup-state снимается и маршрут возвращается к реальной задаче внутри клиники. История неудач при этом сохраняется.

### Груз не теряется при incapacitation

Если к моменту падения уже собрана одна из реальных комбинаций аварийного заказа:

- `bandage x8 + antiseptic x2`, или
- `sterile_bandage x4 + painkillers x3`,

то milestone `clinical_cargo_secured` сохраняется. Эвакуация доставляет игрока с грузом в Лазарет и HUD показывает **«СДАТЬ АВАРИЙНЫЙ ЗАКАЗ»** вместо бессмысленного «вернуться в Лазарет».

## Anti-exploit / anti-softlock правила

- Recovery aid выдаётся только после **первой** клинической incapacitation.
- Вторая и последующие неудачи по-прежнему эвакуируют игрока, но не создают новые патроны/лечение.
- Aid не выдаётся, если медицинский груз уже собран.
- Поздние supply events не меняют исход первого рейса (правило dev8 сохранено).
- Аварийный заказ по-прежнему закреплён на onboarding-окно и не исчезает, если спасённый рейс временно поднял medicine выше shortage.
- Смерть вне Клинического комплекса сохраняет прежнее поведение и не записывается как failed-run среза.

## Save compatibility

- Save schema: **122**, без повышения.
- Новые поля лежат в уже сохраняемом `faction_state.vertical_slice`:
  - `clinical_incapacitations`;
  - `last_incapacitation_day`;
  - `last_incapacitation_floor`;
  - `recovery_pending`;
  - `recovery_aid_issued`;
  - `recovery_aid_day`.
- Dev8/schema 122 без этих полей получает нулевые/false значения и не получает выдуманных неудач или уже потраченной помощи.
- Recovery state проходит production SaveStore round-trip.

# OSTATOK 1.22.0-dev7 — Settlement Crisis / Dynamic Economy

База: `1.22.0-dev6 Random Supply Events`, без изменений визуальных ассетов.

## Что добавлено

### 1. Состояния ресурсов поселения
Каждый из четырёх ресурсов оценивается отдельно:
- `stable` — 55–100
- `strain` — 35–54.99
- `shortage` — 20–34.99
- `crisis` — ниже 20

Общее состояние поселения определяется самым проблемным ресурсом, но экономические эффекты применяются адресно к соответствующей категории товаров.

### 2. Динамический рынок
Кризис больше не является только числом в faction_state.

- Дефицит еды влияет на food / water / household.
- Дефицит медицины влияет на medicine / medical / chemicals.
- Дефицит техники влияет на parts / tools / electronics / technical / fuel.
- Дефицит безопасности влияет на ammo / weapon / armor / security.

При ухудшении ресурса:
- растёт цена соответствующих товаров для покупки;
- поселение немного больше платит игроку за реально нужные товары;
- будущий ресток этой категории уменьшается;
- при полном кризисе надёжные/редкие позиции перестают генерироваться новым рестоком.

Уже лежащий у торговца товар никогда не удаляется магически. Ограничение действует только на последующий ресток.

После всех модификаторов действует жёсткий антиарбитражный spread: продажа торговцу не может стать дороже обратной покупки.

### 3. Аварийные контракты
При `shortage` или `crisis` на фракционной доске появляется повторяемый аварийный контракт по конкретному проблемному ресурсу:
- продовольствие;
- медицина;
- ремонт / техника;
- безопасность.

Контракт не существует при нормальном снабжении. Если для той же проблемы есть authored-контракт, authored-контент остаётся первым, а аварийная поставка занимает дополнительный слот и не вытесняет ручной контент.

Награда аварийной поставки напрямую поднимает соответствующий ресурс поселения.

### 4. Безопасность и supply-events
Низкая безопасность теперь влияет не только на тяжесть инцидента. После закрытия supply-event:
- shortage безопасности может приблизить следующий инцидент на 1 день;
- crisis безопасности — на 2 дня;
- минимальный интервал всё равно не меньше 2 игровых дней.

Движущихся караванов по карте по-прежнему нет.

### 5. Информация игроку
Существующие окна торговли и контрактов теперь показывают состояние поселения:
- `СТАБИЛЬНО`
- `НАПРЯЖЕНИЕ`
- `ДЕФИЦИТ`
- `КРИЗИС`

Также показывается худший ресурс. Если недавно был потерян или спасён рейс снабжения, это выводится как причина/контекст состояния.

Пример:
`КРИЗИС • медицина 12 • последняя проблема: потерян рейс снабжения`

## Save compatibility
Новой обязательной save-схемы не требуется: кризис вычисляется из уже сохраняемых ресурсов фракций. Аварийные контракты восстанавливаются через существующий contract state и проходят sanitize/save roundtrip.

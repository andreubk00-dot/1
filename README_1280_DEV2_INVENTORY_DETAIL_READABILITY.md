# OSTATOK 1.28.0-dev2 — Inventory Detail Readability

Второй срез UI/UX Finalization.

## Проблема

Реальный 640×360 stress-capture оружия с полным набором модов показал два подтверждённых overflow:

- шестистрочное описание оружия в рюкзаке расширяло `Label` до 87 px и заходило под нижнюю action-row;
- тот же полный текст в контейнере перекрывал `ЗАБРАТЬ / ЗАБРАТЬ ВСЕ` и выходил за панель.

## Решение

- Полное описание в рюкзаке сохранено без потери информации, но ему выделена фактически свободная вертикальная зона между сеткой и нижними кнопками.
- Нижняя action-row рюкзака сдвинута вниз внутри прежней панели; сама панель остаётся в 640×360.
- Контейнер использует отдельную компактную inspection-сводку до трёх строк: имя, редкость/количество/вес и релевантные характеристики оружия/ближнего оружия/воды/экипировки.
- Нерелевантная контейнеру подсказка `Быстрый слот` там больше не показывается; полная информация остаётся доступна после переноса предмета в рюкзак.
- Старый `test_inventory_art_contract.gd` синхронизирован с уже действующим SELFTEST-контрактом: strategic items намеренно используют procedural schematic icons.

## Не менялось

- item stats, rarity, weapon condition, mods, magazine state;
- inventory/container grid и drag/drop;
- loot generation и transfer logic;
- quickbar logic;
- save/load schema.

OSTATOK 0.58.0 — CHARACTER MOTION POLISH

Следующий проход персонажа и локомоции поверх 0.57.0.

ПЕРСОНАЖ
- Новый активный cohesive atlas v6 для longgun / pistol / melee, back + front layers.
- Рукава перерисованы как сужающиеся цельные формы без механических круглых/квадратных суставов.
- Уменьшены кисти, локти и толщина предплечий; плечо плавнее входит в силуэт куртки.
- Корпус стал чуть шире, ноги короче и компактнее, чтобы пропорции не выглядели вытянутыми.
- Переработаны борода, лицо, шлем, воротник, vest/webbing, подсумки, колени и ботинки.
- Рюкзак получил более читаемый клапан, компрессионные ремни и боковые карманы.
- Масштаб общего visual-root увеличен с 0.94 до 1.06 для лучшей читаемости деталей без изменения collision shape.

ДВИЖЕНИЕ
- MOVE_SPEED: 53 -> 64 px/s (+20.8%).
- ENEMY_SPEED: 53 -> 60 px/s, чтобы ускорение игрока не уничтожило давление погони.
- Sprint multiplier: 1.28 -> 1.32; базовый спринт теперь 84.48 px/s вместо 67.84 px/s.
- Увеличены walk/sprint acceleration, braking и hard-turn acceleration, сохраняя ощущение массы.
- Distance-driven gait перенастроен на 54 px за walk-cycle и 62 px за sprint-cycle: скорость выше, но ноги не перебирают слишком часто и не скользят.
- Добавлены speed-aware bob, foot-plant impact, перенос веса вбок, небольшая масса вперёд при беге и visual inertia на старт/стоп/резкий разворот.
- Добавлен небольшой body roll на strafe/load transfer; оружие получает часть того же наклона, поэтому хват остаётся связанным.
- 8-direction aim получил hysteresis: мелкое дрожание мыши больше не заставляет весь персонаж мигать между соседними направлениями.

СОВМЕСТИМОСТЬ
- Collision, inventory, survival, save format, AI state machine и weapon gameplay не менялись.
- Проект по-прежнему использует distance-driven animation, поэтому блокировка стеной автоматически останавливает цикл ног.
- Старые procedural arm nodes остаются только для внутренних compatibility tests и всегда скрыты в runtime.

ART / LICENSING
- Новые персонажные пиксели созданы специально для OSTATOK.
- Пользовательские reference images использовались только как art direction; фрагменты/пиксели из них не копировались.
- Сторонние art assets в этом проходе не добавлялись.

# OSTATOK 1.22.0-dev8 — Faction Endgame / Strategic Chains

База: `1.22.0-dev7 Settlement Crisis / Dynamic Economy`.
Визуальные ассеты не изменялись.

## Что добавлено

### 1. Четыре поздние фракционные цепочки
Каждая цепочка требует уровня репутации `ДОВЕРЕННЫЙ` (150+) и состоит из трёх последовательных этапов. Перескочить через этап нельзя.

- Перрон — `ГРАЖДАНСКАЯ СЕТЬ`
  1. `ОБЩИЙ СКЛАД`
  2. `ТРАНСПОРТНЫЙ РЕЗЕРВ`
  3. `ГРАЖДАНСКИЙ ОБМЕННЫЙ ФОНД`
- Рубеж — `СЕТЬ ПАТРУЛЬНЫХ ПОСТОВ`
  1. `РЕЗЕРВНЫЙ АРСЕНАЛ`
  2. `ПЕРИМЕТР: РЕЗЕРВ ПОСТОВ`
  3. `СЕТЬ ПАТРУЛЬНЫХ ПОСТОВ`
- Артель «Механики» — `РЕМОНТНЫЙ КОНТУР`
  1. `«СЕВЕР»: РЕЗЕРВ БОКСОВ`
  2. `«ВЕКТОР»: ИНЖЕНЕРНЫЕ ДАННЫЕ`
  3. `РЕМОНТНЫЙ КОНТУР`
- Лазарет — `МЕДИЦИНСКАЯ СЕТЬ`
  1. `КЛИНИЧЕСКИЙ КОМПЛЕКС №4`
  2. `СТЕРИЛЬНЫЙ РЕЗЕРВ`
  3. `МЕДИЦИНСКАЯ СЕТЬ`

Все задачи используют существующие предметы, POI и contract lifecycle.

### 2. Кризис реально прерывает позднюю стратегию
Каждый этап требует минимально жизнеспособного уровня профильных ресурсов поселения.
Если поселение провалено в дефицит/кризис, следующий endgame-этап не появляется до стабилизации.

Для игроков с 150+ репутации аварийные поставки получают повышенный приоритет на доске и не могут быть вытеснены поздними стратегическими контрактами.
Ранний/mid-game порядок старых authored-контрактов сохранён.

### 3. Необратимые финалы и постоянные эффекты
Финал каждой цепочки сохраняется навсегда в `faction_state.faction_endgame`.
Повторно запустить завершённую цепочку нельзя.

#### Перрон — «ОБЩИЙ ОБМЕННЫЙ ФОНД»
- ежедневная поддержка еды и немного безопасности;
- улучшенный restock еды / воды / хозяйственных товаров;
- небольшой ценовой бонус профильного рынка;
- расширенный резерв воды и аварийных рационов;
- отношения: Лазарет `+12`, Рубеж `-6`;
- открывается совместный маршрут гражданского обмена Перрон ↔ Лазарет.

#### Рубеж — «ПАТРУЛЬНАЯ СЕТЬ»
- ежедневная поддержка безопасности и немного техники;
- улучшенный restock боеприпасов / оружия / брони;
- дополнительный резерв винтовочных патронов и военного снаряжения;
- отношения: Механики `+10`, Перрон `-6`;
- открывается совместный маршрут Рубеж ↔ Механики.

#### Механики — «РЕМОНТНЫЙ КОНТУР»
- ежедневная поддержка технического ресурса;
- улучшенный restock деталей / инструментов / электроники / техснаряжения;
- дополнительный резерв фильтров и редких оружейных деталей;
- отношения: Рубеж `+10`, Перрон `-5`;
- открывается ремонтный маршрут Механики ↔ Рубеж.

#### Лазарет — «МЕДИЦИНСКИЙ РЕЗЕРВ»
- ежедневная поддержка медицины;
- улучшенный restock медицинских товаров;
- дополнительный резерв антибиотиков и trauma kits;
- отношения: Перрон `+12`, Рубеж `-8`;
- открывается медицинский маршрут Лазарет ↔ Перрон.

### 4. Экономика
Постоянные эффекты встроены в уже существующую систему, а не живут отдельными бонусами:
- `FactionEconomy.buy_multiplier/sell_multiplier` учитывают финальную инфраструктуру;
- `TradingMarket.restock` учитывает профильный restock factor и резервные товары;
- `FactionEconomy.daily_tick` применяет постоянное ежедневное снабжение после обычного расхода и маршрутов;
- кризисы dev7 продолжают ограничивать редкий restock даже после завершения цепочки — финал не делает поселение бессмертным.

### 5. UI
Существующие окна торговли и контрактов показывают прогресс фракционной цепочки.
В описании финального задания заранее выводится, что решение необратимо и какие отношения изменятся.
После выполнения игрок получает явное сообщение о завершении фракционной цепочки.

## Save compatibility
Добавлено поле `faction_state.faction_endgame`:
- `chains` — прогресс каждой из четырёх веток;
- `effects` — активные постоянные эффекты;
- `history` — история завершённых этапов.

Старые сохранения без этого поля получают чистое состояние `0/3` для всех четырёх фракций.
Существующая схема сохранения 1.22 не требует отдельной миграции файла.

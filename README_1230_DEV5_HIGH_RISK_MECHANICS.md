# OSTATOK 1.23.0-dev5 — High Risk Mechanics

Механическое продолжение 1.23-dev4 по этапу 4 плана разработки. В этой итерации High Risk объекты получили отдельное состояние, закрытый внутренний доступ, локальные опасные события, последствия зачистки и антифарм-правила. Новый визуал не добавлялся.

## Что добавлено

### Закрытый внутренний сектор

Все четыре авторских High Risk объекта используют уже существующую многоэтажную геометрию, но глубокий сектор больше не является бесплатным проходом.

- переход со 2-го на 3-й уровень начинается заблокированным;
- для аварийного override нужно сначала уничтожить угрозу на текущем уровне;
- после зачистки тот же существующий переход открывает внутренний доступ;
- три глубинных target-farm кеша остаются закрыты, пока внутренний доступ не вскрыт;
- доступ действует только в текущем цикле объекта и после повторного заселения снова закрывается.

Отдельный ключ/пропуск не добавлялся: стратегические предметы относятся к следующему этапу плана. Таким образом сохранено существующее правило no-self-key — нужный для прохода предмет не может лежать за собственной дверью.

### Локальные опасные события

У каждого High Risk объекта есть собственный локальный инцидент с дополнительной группой заражённых:

- карантинный центр №12 — нарушение герметичности;
- «Бастион» — стягивание заражённых к командному двору;
- клинический комплекс №4 — тревога в изоляционном секторе;
- объект «Вектор» — аварийный сигнал командного сектора.

Инцидент появляется только после обнаружения объекта, использует стабильные spawn ID и не воскресает при простой перезагрузке чанка. Полная зачистка фиксируется в состоянии мира и отражается в хронике. При новом цикле повторного заселения угроза возвращается.

### Состояние после зачистки

High Risk объект теперь помнит текущий цикл:

- внутренний доступ вскрыт / закрыт;
- локальный инцидент объявлен / подавлен;
- глубинные запасы истощены;
- объект повторно заселён.

На карте после обнаружения показывается системный статус («активная угроза», «внутренний доступ вскрыт», «зачищен», «истощён • восстановление»), но карта не раскрывает профиль лута, расположение кешей или решение блокировки.

### Антифарм и повторное заселение

Первый проход сохраняет полный авторский loot pool. Повторные циклы являются salvage, а не бесконечным источником лучшего товара:

- `specialized` и `unique` предметы после первой зачистки не восстанавливаются;
- `rare`, `scarce` и обычная добыча возвращаются с пониженным шансом;
- количество восстановленных предметов уменьшается;
- глубинная угроза и локальный инцидент возвращаются полностью;
- внешний периметр повторно заселяется только частично и детерминированно;
- след предыдущей зачистки поэтому остаётся видимым в состоянии мира.

Cooldown существующих target-farm объектов сохранён: 10/12/12/14 дней в зависимости от объекта.

## Save compatibility

- Save schema остаётся **122**.
- Добавлен опциональный верхнеуровневый `high_risk_state`.
- Старые schema-122 сохранения без этого блока безопасно инициализируют четыре High Risk записи.
- Старый сейв не получает бесплатный внутренний доступ.
- Если старый сейв уже содержит defeated ID локального события, dev5 принимает их как завершённое событие без ложного повторного радиосообщения.
- `SaveStore` отклоняет повреждённый `high_risk_state`, если вместо словаря в save находится значение другого типа.

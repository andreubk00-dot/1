# OSTATOK 1.23.0-dev11 — Post-Run Consequences

Dev11 полирует момент после завершения стартового вертикального среза. Цель — чтобы сдача аварийного заказа Лазарета давала понятный системный итог, Миронова реагировала на результат, радио фиксировало последствия, а HUD и карта мягко отпускали игрока обратно в свободную игру без запуска новой глобальной цели.

## Что изменилось

- Исправлена реальная UI-сдача аварийного медицинского заказа. В dev10 предметы сначала удалялись из рюкзака, а затем вертикальный срез повторно проверял текущий инвентарь и мог забыть уже доставленный груз. Теперь завершённый реальный контракт сам является подтверждением доставленного медицинского резерва; до фактической сдачи старое антисофтлок-правило остаётся не-липким.
- Завершение первого цикла получает одноразовый post-run consequence state внутри `faction_state.vertical_slice`; save schema остаётся **122**.
- При первом подтверждённом завершении в «ЭФИР / мировую хронику» добавляется отдельная запись о результате Лазарета. Запись идемпотентна и не дублируется при HUD refresh/save/load.
- Формулировка результата зависит от **текущего** состояния медицинского резерва. Если старый завершённый dev10-сейв загружается позже, когда запасы снова просели, радио не утверждает, что нынешний дефицит снят.
- Доктор Миронова получила одноразовый post-run дебриф. Разговор не обязателен для продолжения игры, но даёт +6 личного отношения и объясняет, что дальше игрок сам выбирает цели.
- Повторные разговоры не могут фармить доверие.
- Остальные NPC Лазарета после завершённого среза комментируют текущий результат снабжения, а не продолжают вести игрока по обучающему маршруту.
- После завершения среза системные маркеры Лазарета/клиники сразу исчезают с карты. HUD на короткое окно показывает итог; после разговора с Мироновой — `СВОБОДНЫЙ МАРШРУТ`, затем полностью возвращается обычная свободная цель.
- Никаких дополнительных ресурсов поселению dev11 не начисляет. Видимое улучшение основано на уже существующих наградах supply event + crisis contract, которые реально меняют `medicine`, цены и restock через SettlementCrisis/TradingMarket.
- Глобальная цель «путь наружу» не добавлялась.

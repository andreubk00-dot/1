# OSTATOK 1.22.0-dev6 — Random Supply Events

База: `1.22.0-dev5 Faction Relations`, собранная поверх пользовательского `DEV4_SETTLEMENTS_DETAIL`.

## Принцип
Караваны НЕ являются движущимися объектами мира. Игра абстрактно моделирует рейсы снабжения и только при срыве материализует временную дорожную сцену из уже существующих игровых объектов.

## Цикл события
- Новый инцидент планируется через 3–6 игровых дней после предыдущего.
- Одновременно существует максимум один инцидент снабжения.
- День 0: `SOS` — охрана ещё жива, груз почти цел.
- День 1: `НЕТ СВЯЗИ` — остаётся один выживший, часть груза потеряна.
- День 2: `РАЗГРОМ` — выживших нет, вернуть можно лишь часть груза.
- День 3: событие закрывается как потерянное, поселение получает штраф к профильному ресурсу и безопасности.

## Фракционные грузы
- Перрон — продовольствие.
- Рубеж — боеприпасы и снаряжение / безопасность.
- Механики — детали и инструмент / технический ресурс.
- Лазарет — медикаменты.

## В мире
- На полевой карте появляется системная опасная отметка даже если сектор ещё не исследован.
- Dynamic supply event имеет приоритет над обычным случайным encounter в выбранном секторе.
- Сцена использует существующий `army_truck`, существующие props, фракционных NPC и заражённых.
- Количество заражённых зависит от тяжести инцидента; при более тяжёлом варианте последний заражённый может быть runner.
- Груз нельзя засчитать, пока рядом живы заражённые этого события.

## Последствия
Спасённый рейс:
- повышает профильный ресурс поселения;
- немного повышает безопасность;
- даёт репутацию и расчётные талоны;
- форсирует ресток торговцев соответствующей фракции.

Чем позже прибытие, тем меньше эффект.

Проигнорированный рейс:
- теряет профильный ресурс;
- снижает безопасность поселения;
- записывается в постоянную историю supply-events.

## Save / compatibility
Состояние хранится внутри `faction_state.supply_events` и проходит существующий save/load pipeline. Старые сохранения без этого поля получают первый инцидент через 3–6 дней от текущего дня, а не немедленно.

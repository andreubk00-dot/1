# OSTATOK 1.20.0-dev4 — Developer Mode / QA Tools

Это отдельная QA-контрольная сборка после операции 4 и до операции 5. Игровой контент
Clinical Complex и Vector не перебалансируется и не получает target-farming раньше времени.

## Управление

- `F10` — открыть/закрыть отдельную панель **РЕЖИМ РАЗРАБОТЧИКА**;
- маленькая кнопка `DEV [F10]` в правом верхнем углу открывает ту же панель;
- `Esc` закрывает dev-панель.

## Вкладка «РЕЖИМ»

- **Неуязвимость**: входящий урон блокируется; каждый кадр HP возвращается к 100,
  очищаются кровотечение, боль, загрязнение/инфекция раны и травмы частей тела. Голод,
  жажда и другие показатели продолжают работать, чтобы survival-механику можно было тестировать.
- **Заражённые не агрятся**: заражённые сбрасывают chase/search/suspicion, прекращают
  движение/атаки и не обнаруживают игрока, пока флаг включён.
- **Выключить всё** — одним нажатием отключает оба dev-флага.

## Вкладка «ТЕЛЕПОРТ»

Список строится автоматически из всех активных `RegionCatalog.POIS`, поэтому новый основной
POI не требует ручного добавления второй кнопки. Для authored compound сначала используется
его `entry` access point с небольшим смещением внутрь безопасной зоны; иначе — центр anchor-sector.
После телепорта чанки немедленно перестраиваются обычным production-путём.

## Release guard

Developer tools доступны только если `application/config/version` содержит `-dev`. Состояние
читов не сериализуется и не добавлено в save schema. При версии `1.20.0` или любой другой
stable-версии панель, HUD-кнопка и input action F10 не создаются.

## Граница scope

- operation 5 integration не выполнена;
- target farming Clinical/Vector не включён;
- новые заражённые 1.21 не добавлены;
- loot tables и баланс двух endgame-локаций dev3 не изменены.

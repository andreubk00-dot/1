# OSTATOK 1.23.0-dev7 — Vertical Slice

Дата: 2026-10-04

## Задача ветки

Собрать из уже существующих систем один понятный первый игровой цикл, не добавляя глобальную сюжетную цель и не превращая игру в линейный туториал:

**старт → Лазарет → реальный дефицит → Доктор Миронова → аварийный supply event → кризисный контракт → клинический High Risk → медицинский груз → возвращение → заметное восстановление поселения.**

Срез включается только для нового прохождения. Сохранения dev6/schema 122 получают совместимый выключенный блок состояния и не меняют экономику мира.

## Что изменилось

- На новом прохождении Лазарет стартует с 26 единицами medicine: это настоящий `shortage`, а не декоративный флаг.
- HUD показывает мягкую системную цель текущего шага среза, но критические survival-цели, активная экспедиция и возврат домой сохраняют более высокий приоритет.
- Полевая карта показывает системную метку Лазарета или Клинического комплекса №4. Во время активного SOS отдельная метка среза скрывается, чтобы не дублировать supply marker.
- Вход в Лазарет фиксирует первое поселение; открытие общей доски Доктора Мироновой фиксирует знакомство с NPC.
- После первой встречи с Мироновой ближайший supply incident подтягивается к следующему игровому дню. Фракцию по-прежнему выбирает существующий need-score; из-за медицинского дефицита первым естественно становится Лазарет.
- Кризисный контракт — существующий `crisis_lazaret_medicine`, без отдельного «tutorial quest».
- После принятия аварийного заказа маршрут ведёт в существующий High Risk `regional_clinical_complex_4`.
- Медицинский груз считается собранным только когда инвентарь реально удовлетворяет одной из альтернатив кризисного заказа: `bandage x8 + antiseptic x2` либо `sterile_bandage x4 + painkillers x3`.
- После сдачи заказа и разрешения supply incident Лазарет должен выйти из `shortage`; завершение первого цикла попадает в мировую хронику.
- Если supply incident проигнорирован и потерян, исход сохраняется как последствие; срез можно закончить последующей стабилизацией мира, без требования «идеального» прохождения.

## Исправления, найденные при сборке среза

1. Карта показывала системный маршрут, но одновременно писала «сначала закрепите дом». Для активного среза текст теперь сообщает, что полевой маршрут доступен до выбора дома.
2. Ранний вариант считал «ценным грузом» слишком малое количество медицинского лута и мог отправить игрока обратно до фактической возможности сдать контракт. Порог привязан к реальным требованиям заказа.
3. Fresh-game pacing отделён от миграции: schema 122 без блока `vertical_slice` никогда не получает стартовый дефицит автоматически.

## Совместимость

- Save schema: **122**, без повышения.
- `vertical_slice` хранится внутри канонического `faction_state`.
- Старые сейвы: блок создаётся выключенным, ресурсы поселений не переписываются.
- Новая игра: инициализация выполняется один раз после проверки `loaded_save`.
- Глобальная цель «путь наружу» не реализовывалась.

## Графика

Новых художественных ассетов нет. Dev6 → dev7: 651 графический файл, 0 изменено / 0 добавлено / 0 удалено. Стартовый HUD и карта проверялись реальным OpenGL capture через Godot 4.7.2 + Xvfb.

После этого среза имеет смысл провести ручной playtest темпа и баланса 2–4 часов: расход боеприпасов/лечения, фактическая сложность клинического комплекса, время на знакомство с Лазаретом, понятность возврата и ощущение изменения поселения. Неутверждённую глобальную цель не внедрять без отдельного решения.

# OSTATOK 1.23.0-dev13 — Sandbox Routes

Dev13 полирует первые 2–3 самостоятельные вылазки после вертикального среза. Сборка не добавляет новую главную цель: она меняет темп обычных фракционных досок так, чтобы свободная игра не сводилась к нескольким одинаковым доставкам перед первой разведкой.

## Что изменилось

- Четыре ранних разведывательных контракта отмечены как `starter_recon` и остаются обычными `discover_poi`-поручениями существующей контрактной системы.
- `ПЕРРОН — ДОРОГА К «ЗАРЕ»`: порог репутации **25 → 8**. Базовый `КУХОННЫЙ РЕЗЕРВ` даёт ровно +8 репутации, поэтому одной реальной поставки достаточно, чтобы открыть разведку.
- `РУБЕЖ — СТАРЫЙ ПОЛИЦЕЙСКИЙ МАРШРУТ`: **25 → 9**. Базовый `ПАТРУЛЬНЫЙ РЕЗЕРВ` даёт +9.
- `МЕХАНИКИ — ДЕПО: ПРОВЕРКА ПОДХОДОВ`: **25 → 9**. Базовый ремонт насоса даёт +9.
- `ЛАЗАРЕТ — РАЙОННАЯ БОЛЬНИЦА` остаётся на **10**: успешный вертикальный срез уже естественно выводит игрока выше этого порога.
- Никакой бесплатной репутации не добавлено. Если игрок не помог новой фракции, её starter-recon по-прежнему закрыт.
- Общие доски теперь явно маркируют тип предложения: `[ПОСТАВКА]` и `[РАЗВЕДКА]`. Личные поручения сохраняют `[ЛИЧНО]`.
- После выполнения starter-recon открываются уже существующие постоянные маршруты снабжения: `route_perron_zarya`, `route_rubezh_police`, `route_mechanics_depot`, `route_lazaret_hospital`.
- Открытый маршрут больше не возвращается в доску как повторяемый контракт; обычный cooldown/history и антифарм остаются прежними.
- Можно одновременно вести по одному контракту от всех четырёх фракций: переключение между поселениями не требует закрывать чужое поручение.
- Районная больница остаётся самостоятельной разведкой без системного маркера и содержит уже существующий медицинский loot/farm profile; dev13 не создаёт скрытого tutorial pin.
- Save schema остаётся **122**. Новых persistent-полей нет.
- Глобальная цель «путь наружу» не добавлялась.

## Почему так

До dev13 после выхода из среза Лазарет уже предлагал осмысленную разведку, но новый контакт с Перроном, Рубежом или Механиками начинался с базовой поставки и затем требовал ещё долгого набора репутации до 25. Это снова толкало ранний sandbox в delivery-loop. Dev13 оставляет базовую помощь обязательной, но делает её достаточным знаком доверия для первой разведывательной работы.

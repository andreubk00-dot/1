# OSTATOK 1.23.0-dev10 — Clinical Run Polish

Dev10 полирует первую обязательную вылазку вертикального среза в **Региональный клинический комплекс №4**. Глобальная цель/«путь наружу» не добавлялись. Save schema остаётся **122**.

## Что изменилось

- Первый сюжетный проход клиники после рейса Лазарета использует отдельный threat budget только пока вертикальный срез не завершён:
  - приёмный сектор: **5** заражённых вместо 7;
  - 2 этаж: **7** вместо 10;
  - 3 этаж: **9** вместо 12.
- Боковые сектора кампуса не облегчены. После завершения вертикального среза клиника снова использует полный authored budget 7/10/12.
- Threat budget больше не зависит от текущего статуса аварийного заказа. Просрочка/re-offer во время вылазки не может внезапно вернуть разгруженному этажу полную популяцию.
- Проверка «этаж очищен» использует тот же effective enemy count, что и спавн. На первом проходе 2 этаж действительно открывается после зачистки семи фактически существующих заражённых — невидимых 8–10 целей нет.
- Подписи переходов клиники стали прямее:
  - `ВЫХОД • ПРИЁМНОЕ ОТДЕЛЕНИЕ`;
  - `АВАРИЙНЫЙ ДОСТУП • 3 ЭТАЖ`;
  - `К ВЫХОДУ • 2 ЭТАЖ`.
- На 3 этаже `Аварийный хирургический резерв` гарантирует один реальный вариант аварийного заказа: **4 стерильных бинта + 3 обезболивающих**. Это обычный одноразовый контейнер, а не новый respawn/target-farm источник.
- До обнаружения клиники HUD показывает advisory readiness: боезапас, лечение, вода. Цели **32 патрона 9×18 / 2 перевязочных средства / 1 вода** ничего не блокируют, а только предупреждают игрока.
- Исправлен антисофтлок медицинского груза: `clinical_cargo_secured` до фактической сдачи отражает **текущий** инвентарь. Если миссионные медикаменты были потрачены в бою, HUD снова ведёт добывать резерв вместо невозможной сдачи.
- После реального набора полного груза появляется короткий feedback о возвращении в Лазарет.
- После закрытия первого цикла финальное сообщение `ПЕРВЫЙ ЦИКЛ ЗАВЕРШЁН` теперь реально видно в день завершения и следующий день; ранее эта ветка UI была недостижима из-за отключения onboarding в тот же момент.

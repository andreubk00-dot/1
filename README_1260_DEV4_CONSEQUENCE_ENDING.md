# OSTATOK 1.26.0-dev4 — Consequence Ending

Dev4 завершает функциональную часть Regional Stability endgame без «выхода из региона» и без окончания sandbox-save.

## Что добавлено

- После 21-дневного Crisis Season каждая из четырёх фракций получает замороженный сезонный итог:
  - `secure` — **УДЕРЖАНО**;
  - `strained` — **НАПРЯЖЕНО**;
  - `scarred` — **ИЗМОТАНО**;
  - `critical` — **КРИТИЧНО**.
- Оценка использует только уже существующие последствия мира:
  - худший финальный canonical resource;
  - минимальный resource, пережитый за сезон;
  - число hardship-дней;
  - supply events `recovered/lost`, закрытые именно внутри сезонного окна.
- Из четырёх фракционных снимков формируется один из пяти региональных итогов:
  - **ОБЩИЙ КОНТУР**;
  - **СЕТЬ УДЕРЖАНА**;
  - **ХРУПКОЕ РАВНОВЕСИЕ**;
  - **РАЗОРВАННЫЙ КОНТУР**;
  - **ОСТРОВА ВЫЖИВАНИЯ**.
- Итог записывается в полевую хронику вместе с четырьмя краткими фракционными сводками.
- Общая доска показывает итог региона; кнопка Crisis Season в «ЭФИРЕ» становится терминальной `ИТОГ РЕГИОНА`.
- Sandbox продолжается после финала. Ресурсы, торговля, кризисы, supply events, контракты и исследование остаются активными.

## Важная правка порядка 21-го дня

Первоначальная dev4-реализация могла зафиксировать outcome до обработки supply-event последнего дня. Исправлено: последнее сезонное давление применяется до supply, но consequence snapshot фиксируется только после same-day supply recovery. Поэтому спасённый на 21-й день рейс и его восстановление учитываются в реальном финальном состоянии.

## Persistence

Save schema остаётся **122**. Outcome хранится внутри уже существующего:

`faction_state["regional_endgame"]["outcome"]`

Он содержит ID итога, исходный `completion_day` и компактные snapshots четырёх фракций. Отдельных top-level save-полей не добавлено.

Старый завершённый dev3 save без outcome мигрирует лениво: dev4 вычисляет итог из сохранённых сезонных metrics, но `resolved_day` остаётся исходным днём завершения сезона, а не днём загрузки.

После первого вычисления outcome заморожен: последующие месяцы sandbox не меняют исторический результат сезона.

## Не изменено

- schema 122;
- 16 named NPC;
- High Risk access / emergency override;
- strategic item access и `cache_3`;
- `loot_refresh_sites`;
- route/project/endgame economy rules;
- supply/crisis recovery coefficients;
- trading;
- death/inventory rules;
- graphical assets.

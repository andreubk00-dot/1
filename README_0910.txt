OSTATOK 0.91.0 — POI SET PIECES

Крупные локации получили тяжёлые объекты с референса промзоны
(tools/wa_poi.py -> poi_props_v1.png, 18 объектов, 2x плотность).

ОБЪЕКТЫ
- депо: товарный вагон, вагон-цистерна (на путях), ж/д светофор;
- Комбинат №7: горизонтальная цистерна на опорах, вертикальный резервуар с
  лестницей, эстакада трубопроводов, погрузчик, поддоны и ящики под брезентом,
  штабель труб, кабельная катушка, трансформаторная подстанция с оградой;
- КПП «Восток»: поднятый шлагбаум (проезд открыт), будка часового с мешками,
  вышка, противотанковые ежи и бетонный блок;
- военный двор / автопарк / плац: «Уралы» под тентом, вышка, ежи, поддоны;
- ГСК «Север» и ремзоны: поддоны, катушки, трубы, подстанция, погрузчик;
- СНТ «Заря»: теплицы, поленницы.

РАССТАНОВКА (_dress_major_poi, вызывается для каждой клетки комплекса)
- набор зависит от типа площадки клетки (ground в poi_catalog);
- вагоны и светофор — фиксированно на путях депо, шлагбаум/будка/ежи — у въезда КПП;
- остальное — по 16 точкам на участках, в детерминированном порядке для клетки;
- проверка места (_poi_spot_free): не на здании (с запасом по высоте фасада и крыши),
  не у двери, не ближе ~26px к любому интерактивному объекту (тайники, двери,
  верстаки), не друг на друге, не на дорогах (кроме путей и въезда);
- крупные объекты имеют коллизию по основанию (вагоны, цистерна, грузовики, будка,
  вышка, резервуар, теплицы и т.д.); эстакада и ежи — без коллизии;
- масштаб: вагоны/цистерна/грузовики/эстакада 0.75, остальное 0.6.

# OSTATOK 1.23.0-dev12 — Free-Play Handoff

Dev12 полирует переход от завершённого вертикального среза к обычной свободной игре. Цель — чтобы после исчезновения обучающего маршрута игрок не оставался без контекста, но и не получал новую обязательную «главную цель».

## Что изменилось

- После завершённого среза HUD снова подхватывает **реально принятый обычный или личный контракт** из существующей контрактной системы. Никакой отдельной sandbox-квестовой системы не добавлено.
- Если активных контрактов нет и дом ещё не закреплён, HUD показывает `ЗАКРЕПИТЬ ДОМ` и прямо поясняет: дом нужен для планирования маршрутов, но **исследовать мир можно и без него**.
- Полевая карта без дома теперь даёт ту же честную причину блокировки кнопки планирования: `Планирование маршрута требует закреплённого дома`. Раньше handoff после dev11 мог выглядеть как тупик или давать неверный контекст.
- После закрепления дома карта возвращается к обычному `Выберите сектор и назначьте цель`, а короткое dev11-сообщение `СВОБОДНЫЙ МАРШРУТ` снова может появиться при отсутствии активных задач.
- Контракт Лазарета `РАЙОННАЯ БОЛЬНИЦА` остаётся обычным `discover_poi`-контрактом, но его порог репутации снижен **25 → 10**. Это делает его естественной первой самостоятельной разведкой после успешного стартового цикла: спасённый рейс + аварийная поставка дают достаточно репутации без бесплатного бонуса.
- При репутации 9 этот контракт ещё не доступен; при 10 уже появляется в обычной доске Лазарета.
- Принятый `РАЙОННАЯ БОЛЬНИЦА` показывается в HUD с настоящим прогрессом (`объект ещё не разведан` / `ГОТОВО К СДАЧЕ`).
- Dev12 **не создаёт системный маркер** районной больницы на карте. Игрок по-прежнему сам исследует город и использует обычную карту/контракты.
- Завершённый vertical-slice state не переактивируется. Save schema остаётся **122**.
- Глобальная цель «путь наружу» не добавлялась.

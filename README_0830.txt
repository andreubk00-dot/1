OSTATOK 0.83.0 — BUILDING & LOCATION VARIETY
=============================================

Цель прохода
------------
Поверх макроструктуры региона 0.82 сделать районы физически различимыми не только
по табличке/луту, а по типам построек, внутренним планировкам, фасадам, крышам и
функциональным ролям. Одновременно заложить metadata hooks под будущие убежища,
инфраструктуру, задания и POI.

Что изменено
------------
1. world/building_catalog.gd расширен до authored archetype profiles.
   Каждый тип здания теперь задаёт layout/facade/roof/yard, смещение входа и
   логичное положение основного контейнера.

2. Добавлены разные внутренние планы для жилых домов, подъездов, гаражных рядов,
   аптек, продуктовых, кафе, сервисов, цехов, складов, ремонтных боксов, АБК,
   железнодорожных построек, дач, домов, сараев, лесных кордонов, КПП, казарм,
   военных складов и узла связи. Внутренние перегородки имеют collision и проходы.

3. Входы больше не обязаны быть строго по центру. Archetype задаёт door_x, а
   наружная wall collision автоматически строится вокруг реального проёма.

4. Фасады получили типовые языки: гаражные ворота, промышленные пролёты,
   деревянные крыльца, военную маркировку, дополнительные окна/служебные детали.

5. Крыши получили типовые профили: жилой flat roof, промышленное оборудование,
   условно скатные дачные кровли, военные/связные элементы.

6. Дворовое окружение теперь зависит от назначения здания: канистры/инструмент у
   гаражей, бочки и коробки у промки, хозяйственный мусор у дач, мешки/барьеры у КПП.

7. Контейнеры сохраняют прежние persistent ids cache_0..cache_3, но размещаются
   внутри логичной части конкретной планировки. Это сохраняет состояние лута.

8. На building node добавлены metadata hooks для будущих систем:
   world_archetype, layout_profile, facade_profile, yard_profile, location_tags,
   utility_hooks, shelter_score, district_id, poi_id, loot_profile.

9. QA расширен флагом --qa-building-index=0..3 совместно с --qa-world-chunk=x,y,
   чтобы проверять конкретный интерьер со снятой крышей.

10. Save schema поднята до 83 и отдельно хранит building_layout_version=2.

QA

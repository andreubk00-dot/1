# OSTATOK 1.34.0-dev1 — Full Playthrough Beta Baseline

Первый полный beta-интеграционный проход после Feature Lock.

Покрыты три контрастных сценария от нового старта до регионального endgame:
- supported: активная поддержка сети и поселений;
- strained: минимальные допустимые резервы и выборочная поддержка;
- unsupported: без прямой поддержки в Crisis Season.

Все сценарии проходят onboarding, sandbox routes, settlement projects, faction endgame chains, Regional Stability, 21-дневный Crisis Season, consequence ending, post-ending sandbox и production save/reload.

Единственная production-правка этого среза: заголовок окна теперь берёт текущую версию из application/config/version вместо старого hardcoded 1.26.0-dev4.

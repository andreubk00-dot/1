# OSTATOK 1.26.0-dev3 — Crisis Season Pressure

Crisis Season now applies real pressure for 21 days using existing canonical faction resources.

- Perron: food + security demand.
- Rubezh: security + technical demand.
- Mechanics: technical + security demand.
- Lazaret: medicine + food demand.
- Additional deterministic load spikes on season days 7 and 14.
- Same-day duplicate ticks cannot charge pressure twice.
- Direct supply/player recovery remains outside the seasonal drain.
- Persistent metrics record per-faction hardship days and resource minima for the later consequence ending.

No separate disaster currency, no new loot key and no global escape route are introduced.
Save schema stays 122.

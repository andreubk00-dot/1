## Выполнено в ветке

- Центр экрана: компактная немодальная панель подбора предметов с иконками из существующего `_make_item_icon`, названием, количеством и цветом редкости, максимум 3 карточки.
- Получение с земли, «Взять выбранное» и «Взять всё» вызывают тот же показ и только после успешного переноса вещей в инвентарь.
- Новая панель не перехватывает клики, а через 2 секунды исчезает. Системное текстовое уведомление перенесено ниже для устранения наложения.
- Наведение сохраняется строго в сторону курсора мыши, без автоматического выбора врага.
- Удержание левой кнопки ведёт огонь из любого огнестрельного оружия, включая полуавтоматическое, **не обходя штатный `fire_cooldown`, перезарядку и патроны**. Меню/карта/отдых блокируют стрельбу; ближний бой остаётся одиночным действием.

## Следующие самостоятельные задачи (без текущих побочных изменений)

1. Привязка оружия к точкам хвата для каждого типа и каждого направления прицеливания, сравнение реальных кадров неподвижно/бег/выстрел/перезарядка/смена оружия; не накладывать новое оружие поверх уже запечённого в анимациях.
2. Повышение детализации анимации корпуса, ног, рук, отдачи; визуальные кадры для каждого оружия.
3. Полноценная художественная переработка предметов без общих пустых fallback-иконок; уведомления редкости и отдельные кадры редких наград.
4. Перепроверка крепления источников света и декораций к реальной геометрии стен/полу, исключение перекрытия проходов.
5. Улучшение семейства локаций: новая тематическая обстановка и наборы реквизита по биомам вместо случайного рассыпания объектов.
6. Аудит существующих навыков/оснащения, затем отдельный проект прогрессии способностей и тесты совместимости сохранений.

**Важно:** текущая игра — 2D-сцена Godot; художественные улучшения требуют смотреть и исправлять реальные спрайты, а не подменять их описаниями.

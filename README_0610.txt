OSTATOK 0.61.0 — REFERENCE INTERFACE PASS
=========================================

Цель прохода
- приблизить игровую подачу к утверждённому референсу не копированием пикселей,
  а компоновкой: мир остаётся видимым, а состояние выжившего, инвентарь и верстак
  читаются одновременно как единый полевой интерфейс.

Что изменено
- HUD больше не исчезает при открытии инвентаря: верхние survival-панели остаются
  на экране и дают непрерывный контекст здоровья, времени, зоны и текущей цели;
- инвентарь перенесён в нижнюю левую часть экрана и уменьшен как цельная пиксельная
  панель, поэтому он больше не превращает игру в полностью чёрный модальный экран;
- экипировка получила отдельную компактную панель рядом с инвентарём;
- лут-контейнер использует ту же компактную компоновку;
- верстак теперь открывается совместно с инвентарём: ресурсы слева, рецепты и
  требования справа, без скрытия всего остального интерфейса;
- панели получили общие индустриальные рамки/угловые детали с HUD и умеренную
  прозрачность, чтобы интерьер и персонаж не пропадали за UI;
- добавлен QA-режим --qa-workbench для детерминированной проверки интегрированного
  интерфейса верстака;
- логика инвентаря, drag-and-drop, крафт, item instance identity, survival state,
  оружие, AI и формат сохранений не менялись.

Art / reference policy
- пользовательский референс используется только как направление композиции,
  плотности и визуальной иерархии;
- пиксели, фрагменты интерфейса и сторонние ассеты из референса не копировались.

Проверка
- Godot 4.7.2 clean import: OK;
- normal / inventory / clinic / player / infected / infected-motion / facade / exterior / workbench: exit 0, SELFTEST OK, ERROR 0, WARNING 0 в headless runtime;
- clinic + inventory X11/OpenGL visual capture: OK;
- clinic + workbench X11/OpenGL visual capture: OK;
- в виртуальном X11 окружении остаются только системные предупреждения V-Sync/ALSA, не связанные с игровым кодом.

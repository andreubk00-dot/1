# Полные прогоны баланса v1.8.21 — 8 октября 2026

Добавлен детерминированный симулятор `tests/simulate-runs.cjs`. Он выполняет исходный Game.update, использует боевую экономику, автоматическую покупку доступных улучшений трёх защитников, выбирает реликвии, применяет Импульс, режим Командира и ручную стрельбу; заглушены только графика, звук, интерфейс и запись сохранений.

Запуск из корня репозитория:
```bash
node tests/simulate-runs.cjs fresh 12345 1
node tests/simulate-runs.cjs progressed 12345 1
node tests/simulate-runs.cjs veteran 12345 1
```

## Результаты одного фиксированного seed
| Профиль | Пройдено волн | Игровое время |
| --- | ---: | ---: |
| fresh | 28 | 609 сек |
| progressed | 34 | 818 сек |
| veteran | 44 | 1157 сек |

Для `veteran` при искусственном увеличении радиуса наведения до ×1.35 пройдено 52 волны; ×1.75 — 51; ×2 — 52. Увеличение дальности само по себе не решает прогрессию. Это не репрезентативный игровой тест и не основание для непосредственного увеличения дальности.

**Вывод:** полноценный прогон опровергает предположение, что снижение HP боссов само по себе делает волны 60–120 проходимыми. Нужна дополнительная работа над приростом DPS, ценой боевых улучшений, скоростью волн и/или их механиками, затем повторение тестов на нескольких случайных seed и профилях. Не следует выпускать текущую экспериментальную ветку как стабильную.

Ограничения: автоматические решения игрока, не физический браузер, не тесты Safari/Android; не проверяет реальные навыки игроков и доступность мета-прокачки за указанное число игровых часов. Не изменены текущие публичные сервисы Render.

## Дополнительная итерация: поздний урон и дальность

В экспериментальной ветке добавлена более мягкая стоимость **боевых** улучшений после 8-го уровня: рост 1.15 вместо 1.49. С 9-го уровня урон умножается на 1.27 за следующий уровень сверх исходной линейной формулы. Начальные уровни сохранены. Дальность перехвата зависит от Лаборатории урона, мастерства и звёзд; общий бонус ограничен +85%. Описание эффекта Лаборатории обновлено на RU/EN. Схема сохранения осталась 21.

Повторены реальные полные симуляции `Game.update()` с автоматической прокачкой/Импульсом/ручным огнём на трёх фиксированных seed:

| Профиль | Seed 12345 | Seed 42 | Seed 8675309 |
| --- | ---: | ---: | ---: |
| Fresh | 28 | 28 | 28 |
| Progressed | 34 | 34 | 34 |
| Veteran | 120 | 120 | 120 |

**Вывод:** поздний контент теперь достижим для сильно прокачанного отряда в выбранных тестах, но граница 30–35 волн остаётся слишком резкой для среднего профиля. Не выдавать это за оценку удержания живых игроков. Результат относится к настроенному алгоритму автопрокачки, фиксированным seed и базовой сложности. Изменения ещё не опубликованы на Render; до выпуска требуется проверка ранних/средних волн, графический тест браузеров и сохранений.

Проверки: `tests/balance-v1821.test.cjs`: **21/21** успешно, включая стоимость, боевой урон, дальность, PWA и неизменность схемы сохранений.

## Плавный переход Разлома — итерация 2026-10-08

На волнах 31–55 для **рядовых и элитных** врагов применяется плавная огибающая: с 30-й по 35-ю волны коэффициенты HP/скорости изменяются от 1 до 0.70/0.88, затем к 55-й возвращаются к 1. Это не применяется к боссам и не меняет волны 1–30. Функция `Game.riftEase(w)` реализована в обеих HTML-версиях. Сохраняется номер схемы сохранения 21.

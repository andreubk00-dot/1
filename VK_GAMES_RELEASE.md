# «Бесконечные защитники» — VK Games / Одноклассники

## Сборки

Обе версии собираются из проверенного `iphone/index.html` без изменения игрового баланса и сохранений v21.

- **vk-games-html5.zip** — запуск во ВКонтакте.
- **odnoklassniki-html5.zip** — запуск в Одноклассниках.

В архиве каждой версии: `index.html` и локально упакованный официальный `VK Bridge 2.15.0` (`bridge.bundle.js`). Готовые ZIP доступны в артефактах workflow **VK Games and OK HTML5 Packages** на вкладке GitHub Actions. Для локальной пересборки выполнить:

```bash
npm install --no-save --no-package-lock @vkontakte/vk-bridge@2.15.0 esbuild@0.25.12
node tools/build-vk-games.cjs
node tests/vk-games-platform.test.cjs
```

Итоги получаются в `dist/vk` и `dist/ok`.

## Что уже работает

- Одинаковый игровой процесс из mobile/HTML5-версии.
- VK Bridge: инициализация, приглашение друзей, полноэкранная и rewarded-реклама.
- Награда выдаётся **строго при успешном ответе платформенного API** (`result===true`). При ошибке, отсутствии SDK и повторных вызовах бесплатного начисления нет.
- Время рекламы исключается из игрового времени штатным механизмом внешней паузы.
- Локальные ключи сохранения отличаются: `endless_defenders_vk_save_v1` и `endless_defenders_ok_save_v1`; формат самих сохранений не меняется.

## Что обязательно выполнить перед выпуском

1. Создать игру в [кабинете VK для разработчиков](https://dev.vk.com/ru/admin/create-app). Платформа VK Games управляет размещением и во ВКонтакте, и в Одноклассниках.
2. Загрузить соответствующие пакеты в кабинет (или указать HTTPS-URL, если для выбранной категории запрашивается размещение на внешнем хостинге).
3. Запустить предпросмотр **внутри реальных клиентов VK и ОК** и подтвердить, что VK Bridge и рекламная сеть реально работают на обеих площадках. Сами автоматические mock-тесты этого не гарантируют.
4. Подключить договор монетизации VK / кабинет выплат и требуемые рекламные настройки. Не считать тестовые показы источником дохода.
5. Подтвердить соответствие условиям модерации, политике персональных данных, ограничениям рекламы.
6. **Облачная синхронизация и внутриигровые покупки пока отключены**: для большого сохранения v21 нельзя безопасно использовать короткую запись VK Storage; выдача покупок требует проверки платежей на сервере. Сейчас сохранения хранятся локально в браузере и не синхронизируются между устройствами. Перед полноценным коммерческим запуском следует решить вопрос аккаунтного сохранения и платежного бэкенда.

Не загружайте Яндекс-сборку в VK: у неё другая платформа рекламы и SDK. Не смешивайте разные платформенные сохранения при общем домене.

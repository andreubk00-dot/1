# OSTATOK 1.23.0-dev2 — Radio / World Chronicle

База: текущая `1.23.0-dev1` с High Risk visual rework поверх механической основы `1.22.0 Stable`.
Визуальный слой dev1 сохранён без отката; этот этап добавляет только механику и UI хроники.

## Что добавлено

- `world/world_chronicle.gd` — каноническая сохраняемая хроника мира внутри `faction_state`.
- История ограничена 64 последними сообщениями, сохраняет день/время, тип и фракцию.
- Старые save schema 122 загружаются без обязательной миграции: отсутствующая хроника создаётся автоматически.
- На полевой карте появилась вкладка **ЭФИР** с индикатором непрочитанных сообщений.
- Хроника получает только последствия уже существующих систем, не генерирует задания и награды.

## Источники сообщений

- создание, ухудшение, потеря и спасение supply event;
- переход поселения в напряжение / дефицит / кризис и последующая стабилизация;
- открытие постоянных маршрутов снабжения;
- конфликтные решения и изменения отношений фракций;
- этапы и финалы фракционных стратегических проектов.

Сообщения намеренно написаны как эфир/слухи мира, без вывода внутренних коэффициентов и сухих системных чисел.

## Исправление механики времени

Исправлен баг сна через полночь: раньше `_simulate_rest()` увеличивал `world_day`, но обходил суточные тики фракционной экономики, supply events, restock и контрактов. Теперь обычный ход времени, debug-промотка и сон используют один обработчик `_process_world_day_rollovers()`.

Это закрывает эксплойт, при котором игрок мог перескакивать суточное потребление поселений и часть событий снабжения с помощью сна.

## QA

Добавлено:
- `tests/test_world_chronicle_123.gd` — append/dedupe/history cap/read state/sanitize roundtrip;

- `tests/test_rest.gd` расширен проверкой, что сон через полночь запускает faction daily economy и создаёт запись хроники при смене состояния поселения;
- High Risk visual version gate обновлён с dev1 на dev2 без изменения самого визуального контента.

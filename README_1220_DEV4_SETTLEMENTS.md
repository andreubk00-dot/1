# OSTATOK 1.22-dev4 (settlement pass): faction settlement identity

This pass continues from 1.22-dev3 Contracts / World Influence. It only changes how the four
faction settlements look and how they are laid out. The version string, save schema, NPCs,
traders, contracts and economy are unchanged.

## Problem

All 36 settlement sectors (4 settlements × 3×3) used one template: the same three boxes in the
same slots, one road barrier, two fences across every sector, and the generic compound floor.
Because the `settlement_*` grounds had no dressing, blood/debris decals and random parked cars
also leaked into the "safe" towns.

## What changed

- **Authored plan per sector** (`world/faction_settlement_catalog.gd → PLANS`). Each sector picks
  its own buildings (0–4 slots plus optional extra sheds/boxes) and 5–16 set pieces that fit its
  role. Building ids and cache ids stay slot-stable.
- **New art atlas `settlement_props_v1.png`** (36 structures, generated by
  `tools/wa_settlement.py` with the shared `wa_core` 3/4 renderer, same light and outline as
  `poi_props_v1`):
  - Перрон: market stalls, water tower, vegetable beds, laundry lines, field kitchen, railway
    platform canopy, radio mast, water point, chicken coop, long tables, fire barrels;
  - Рубеж: sandbag nests, HESCO rows, army tents, flag pole, searchlight towers, earth-covered
    ammo bunker, BTR, jersey blocks;
  - Механики: jib cranes, scrap heaps, wind turbines, fuel station, car on blocks, forge,
    solar rig, converted container shop;
  - Лазарет: medical tents, decontamination frame, triage canopy, herb beds, incinerator,
    oxygen rack, ambulance, wash station.
- **Faction perimeters** (`settlement_walls_v1.png`): salvaged plank palisade / FBS blocks with
  razor wire / corrugated sheet with a hazard band / whitewashed mesh. Walls now run only along
  the outer edge of the 3×3 town. The two fences that crossed every sector are gone.
- **Gates** open in the middle of every side, plus a service gate in the south-east sector.
  Each gate has faction posts, pennants, a name board, a lamp and a faction control post
  (fire barrel / guard booth + boom barrier / hazard threshold / wash station).
- **Ground language**: trodden lanes, grass, a brick market square and the old branch line
  with boxcars (Перрон); asphalt with dashed lines and a painted parade ground (Рубеж);
  oil-stained concrete with yellow lane marks (Механики); light paving with bordered paths,
  lawns and painted red-cross pads (Лазарет).
- **Night life**: fire barrels, the field kitchen, the forge and the incinerator, stall lanterns,
  searchlights and string lights over the squares use the existing exterior practical lights,
  which fade in with the night factor.
- Safe settlements no longer get blood/debris decals, random cars, random trees or generic
  street furniture.

## Safety rules kept

- Every piece passes a placement check: no building footprint, no door swing, no NPC circle.
  A blocked piece is skipped and recorded in the chunk meta `settlement_pieces_skipped`.
- The sector cross-lanes and every gate opening stay physically free.
- No containers, loot or persistent keys were added.

## QA

- New: `tests/test_settlement_layout_122.gd` (356 checks). It covers lanes, gates and NPC
  clearance, requires that every planned piece is placed, and checks building count, variety
  and the signature structures of each faction.
- Visual QA: `tests/qa_settlement_capture.gd` renders every sector, whole-town overviews and
  gameplay-zoom close-ups (day/night) to PNG:
  `xvfb-run godot --path . --rendering-driver opengl3 --script tests/qa_settlement_capture.gd -- --qa-output=<dir> [--qa-overview|--qa-closeup] [--qa-night] [--qa-only=<faction>]`
- Existing settlement, faction, trading, contract and world regressions pass unchanged.

Target engine: Godot 4.7.2 Stable.

# OSTATOK 1.26.0-dev1 — Regional Stability Foundation

Первый срез 1.26 создаёт долгосрочную региональную цель без «выхода из региона».

## Что считается готовностью

Глобальная готовность полностью выводится из существующего schema-122 состояния:

- открыты 4 starter reconnaissance routes;
- завершены 4 settlement projects;
- завершены 4 faction endgame chains / постоянные сети;
- все 4 поселения находятся в состоянии STABLE по food / medicine / technical / security (порог 55).

Каждый слой даёт 25% общей готовности. Активный supply SOS не отнимает проценты, но временно
блокирует переход к будущему Crisis Season, пока текущий инцидент не закрыт.

## Интеграция

На общей контрактной доске выводится компактная строка `УСТОЙЧИВОСТЬ ...` и ближайший
незакрытый рубеж. Персональные доски не превращаются в глобальный endgame UI.

## Persistence

Нового persistent `regional_stability` state нет. После загрузки старого schema-122 save
готовность пересчитывается из `world_routes`, `settlement_projects`, `faction_endgame`,
ресурсов поселений и текущего supply-event.

Следующий срез 1.26 должен добавлять отдельное сохраняемое состояние Crisis Season только
после этой derived foundation.

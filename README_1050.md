# ОСТАТОК 1.05.0 — World Stability

Основа: предоставленная пользователем OSTATOK 1.04.0 WORLD SURVIVAL POLISH. Это первый этап продолжения после аудита: исправление подтверждённых ошибок без расширения числа игровых подсистем.

## Исправления

- Частичный подбор выброшенного стака теперь обновляет его постоянную запись. Остаток не восстанавливается до исходного количества после загрузки чанка или сохранения.
- Частично подобранный предмет фиксированной генерации переводит остаток в существующий список dropped_items, а исходный spawn помечается подобранным. Сохраняются количество и мировая позиция, включая отрицательные координаты чанков.
- Предмет, уже ожидающий удаления, нельзя подобрать повторно в том же кадре.
- При строительстве проверяется положение и игрока, и места установки относительно крыши. Нельзя установить обогреватель снаружи из помещения или дождесборник под крышей с улицы.
- Баррикада проверяется всей физической формой 38×14 с учётом поворота. Её край не должен пересекать стену, даже если луч к центру свободен.
- Кнопка строительства и действие установки используют одну проверку условий. Отказ не списывает материалы и не создаёт запись объекта.
- Исправлено вертикальное выравнивание названия, числового HP и состояния в строках обороны. Причина: Label сохранял высоту, рассчитанную до применения мелкого шрифта.
- Исправлены метаданные версии: в исходной 1.04 project.godot ещё показывал 1.03.0.

## Совместимость

save_version = 97, новых постоянных полей нет. Имя приложения сохранено для прежнего каталога user://. География, ассеты, экипировка, темп заражённых из 1.04 и удаление лишних механик в 1.03.1 сохранены. Уже размещённые объекты не перемещаются: новые ограничения применяются к новым установкам.

Исправление подбора предотвращает новое дублирование; оно не может определить и удалить предметы, которые игрок уже получил из-за старой ошибки.

## Запуск

Откройте project.godot в Godot 4.7.2 и запустите main.tscn / F6 либо проект / F5. Для проверки своего старого сохранения предварительно сделайте его копию. Проект использует прежний каталог сохранений, поэтому новая папка проекта сама по себе не создаёт отдельный сейв.
